# تطبيق النواق APK

هذا مشروع Android خفيف يفتح متجر النواق `https://alnuwaq.com` داخل تطبيق WebView.

## إخراج APK مجانًا عبر GitHub Actions
1. أنشئ مستودع GitHub جديد وارفع محتويات هذا المجلد إليه.
2. افتح تبويب **Actions**.
3. اختر **Build Alnuwaq APK** ثم **Run workflow** (أو سيعمل تلقائيًا بعد الرفع على main).
4. بعد نجاح البناء افتح التشغيل ثم قسم **Artifacts**.
5. حمّل `alnuwaq-apk` وستجد بداخله `app-debug.apk` الجاهز للتثبيت المباشر.

## بيانات التطبيق
- الاسم: النواق
- Package: `com.alnuwaq.app`
- الرابط: `https://alnuwaq.com`
- Android 7.0 أو أحدث

> هذه النسخة للتثبيت المباشر. يمكن لاحقًا إضافة شعار النواق الحقيقي وشاشة بداية وزر تتبع مخصص داخل التطبيق.
